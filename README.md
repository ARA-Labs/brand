# ARA Lab logo kit

Vector logo kit for ARA Lab (legal entity: ARA Commons, Inc.). Everything
in `out/` is generated by `gen_kit.py` from the approved mark raster in
`source/`, so the exports are reproducible and the script is the source of
truth — edit the script, re-run it, never hand-patch an SVG.

## What's here

- `source/brace-a_mark.png` — the approved `{A}` mark raster the vectors
  are traced from.
- `gen_kit.py` — generator: potrace-traces the mark, sets the "ARA LAB"
  wordmark in American Typewriter (regular, letterspaced caps), and
  exports SVG plus PNG at every size.
- `out/` — the shipping assets.

## Assets

| File stem | Use |
| --- | --- |
| `ara-lab-mark` | mark alone: favicon, avatar, app icon (32–1024 px) |
| `ara-lab-lockup-horizontal` | mark + wordmark side by side: site header, deck footer, letterhead |
| `ara-lab-lockup-vertical` | stacked mark over wordmark: title slides, posters, square crops |

Each comes in ink (`#1a1530` on light backgrounds) and a `-white` variant
for reversing out of dark. Palette per `brand-direction.md` in the parent
repo: deep ink `#1a1530`, warm peach `#e8a878`.

## Regenerating

```bash
python3 gen_kit.py            # SVG + PNG
python3 gen_kit.py --svg-only # skip the Chrome rasterization pass
```

Requires `potrace` (Homebrew), `fontTools`, `Pillow`, `numpy`, and Google
Chrome for the headless PNG export. The wordmark font is macOS's
`AmericanTypewriter.ttc`.
